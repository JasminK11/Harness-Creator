# Harness-Quellen — Single Source of Truth
#
# Eine Zeile pro Repo. Format: <git-url> [#branch]
# Zeilen mit # am Anfang sind Kommentare.
#
# Neues Repo aufnehmen:  Zeile hier eintragen, dann /harness-update laufen lassen.
# Repo entfernen:        Zeile löschen (oder auskommentieren), dann /harness-update.
#
# Marker am Zeilenende:
#   !bulk   Repo liefert sehr viele Bausteine. Bleibt katalogisiert, taucht aber
#           nicht in der Standardsuche auf — sonst verdrängt es alles andere.
#           Zugriff nur mit --repo, --domain oder --all.
#   !full   Erzwingt volle Sichtbarkeit, auch wenn das Repo über der
#           Automatik-Schwelle von 2000 Bausteinen liegt.
#   Ohne Marker: ab 2000 Bausteinen automatisch bulk.
#
# Vertrauenszeile — unmittelbar ÜBER der Repo-Zeile, ohne Leerzeile dazwischen:
#   # Vertrauen: offiziell | gepflegt | unbekannt — <Halbsatz Begründung>
#
#   offiziell  Vom Hersteller der Plattform selbst herausgegeben.
#   gepflegt   Erkennbarer Qualitätsanspruch UND Belege dafür: laufende Commits,
#              einheitliches Format, oder eine eigene Auswertung in knowledge/.
#   unbekannt  Nichts davon geprüft. Kein Urteil über die Qualität — eine Aussage
#              darüber, dass niemand hingesehen hat.
#
#   Die Stufe ist eine Angabe für Menschen. `show` hängt sie an die Repo-Zeile,
#   sonst ändert sie nichts: keine Sortierung, keinen Punktwert, keine Auswahl.
#   Ein Vertrauens-Tiebreaker in der Suche wurde gebaut und wieder verworfen —
#   er hob beschreibungslose Einträge nach oben (knowledge/06, M5).
#   Fachliche Passung schlägt Herkunft. Die Stufe entscheidet erst, wenn zwei
#   Bausteine dasselbe Problem gleich gut lösen.
#
# Aufnahmekriterien für ein neues Repo (das einzige Human-in-the-Loop-Gate,
# das diese Bibliothek hat — knowledge/04, Abschnitt 5.1):
#   1. Enthält es überhaupt Claude-Bausteine? SKILL.md, agents/, commands/,
#      hooks/, .claude/. Ein Repo ohne Bausteine kostet Klonzeit und liefert null.
#   2. Ist der Bestand nach dem ersten `extract` grösser als null? `lint` meldet
#      Repos mit null Katalogeinträgen.
#   3. Trägt es eine Vertrauenszeile? Ohne Zeile gilt nicht "gut", sondern
#      "ungeprüft" — dann schreib das hin, statt die Zeile wegzulassen.
#
# Die Klone liegen NICHT hier, sondern im Klon-Verzeichnis der Bibliothek
# (~/.harness-sources, überschreibbar mit HARNESS_SOURCES — ausserhalb von
# Cloud-Sync-Ordnern, sonst synct dieser hunderte MB .git-Objekte).
